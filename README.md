# Читальня

Читалка книг (PWA) з онлайн-пошуком і офлайн-бібліотекою. Без збірки, чистий HTML/CSS/JS.

- Формати: EPUB, FB2 (у т.ч. .fb2.zip), TXT (UTF-8 / Windows-1251)
- Пошук: Project Gutenberg, Вікіджерела (укр), Internet Archive
- Бібліотека в IndexedDB, прогрес читання, зміст, теми, розмір шрифту

## Запуск на GitHub Pages
1. Створи репозиторій (наприклад `Chytalnia`), завантаж туди всі файли з цієї папки.
2. Settings → Pages → Branch: main / root.
3. Відкрий посилання на телефоні й додай на головний екран.

Локально: `python3 -m http.server 8000` у цій папці.
